# Beginner usability test (PRD 18.4, 16.2)

Not run yet. It needs 3–5 people.

For each participant:
1. Task: "React 버튼 이동을 브라우저로 확인하고 싶다." Run `python -m lab select "<that sentence>" --stack react --tools Read,Bash,Write,Edit --no-rubric` and show them the output.
2. Ask them: which candidate would you pick, and why? What do you make of the NO_SKILL option? Which unknowns did you notice?
3. Record: whether they finished, where they got stuck (think-aloud), whether they over-trusted the recommendation, and time taken.

One file per session: `YYYY-MM-DD-<id>.md`. 3–5 people is a starting point for finding usability problems, not a representative sample.
